# 基于节约算法的动态物流调度系统

## 简介

本系统是一款基于 **Clark-Wright 节约算法** 的动态物流调度管理平台，采用 Python + PyQt6 开发，集成了高德地图、实时 GPS 定位、订单全生命周期管理等功能，适用于物流调度场景的演示与软件著作权申报。

---

## 主要功能

### 管理员端
- 🗺️ **高德地图集成**：支持北京、上海、广州、深圳、成都 6 个城市切换，实时展示配送路线
- 🎯 **Clark-Wright 节约算法**：自动优化配送路径，降低运输成本
- 📋 **订单全生命周期管理**：待分配 → 已分配 → 取货中 → 配送中 → 已送达，状态可追溯
- 📊 **数据分析**：Canvas 绘制的成本分析图、车辆利用率图
- 💰 **成本参数配置**：支持燃油单价、百公里油耗、过路费等 6 项参数动态调整
- 📡 **实时监控**：所有在线驾驶员位置动态展示
- 📥 **导出调度方案**：支持导出为 Excel 文件

### 驾驶员端
- 📱 **手机号 / 工号双模式登录**
- 📍 **GPS 定位**：基于当前城市配送中心实时定位，模拟位置漂移
- 🗺️ **高德导航地图**：配送路线可视化，起终点标注
- ✅ **任务全流程操作**：取货 → 导航 → 送达确认 → 异常上报
- 🎨 **简洁卡片风界面**：白底蓝主题，视觉清爽

## 核心算法

本系统采用 **Clark-Wright 节约算法（C-W Savings Algorithm）** 进行车辆路径优化：

1. 计算所有客户节点之间的节约里程
2. 按节约量从大到小排序
3. 依次合并路线，满足车辆载重约束
4. 输出最优配送方案及成本
